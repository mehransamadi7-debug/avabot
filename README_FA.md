# ربات ارزیابی اولیه شانس ویزای تحصیلی آوا

## امکانات نسخه فعلی

- پرسش‌نامه مرحله‌ای داخل تلگرام
- امتیازدهی اولیه از ۱۰۰
- دریافت شماره تماس با رضایت کاربر
- ذخیره لیدها در SQLite
- ارسال فوری لید جدید برای ادمین
- لینک اختصاصی معرفی برای هر کاربر
- دکمه اشتراک‌گذاری برای رشد ویروسی
- آمار مدیر با دستور `/stats`
- خروجی CSV لیدها با دستور `/export`
- امکان ارزیابی مجدد

> این ربات احتمال واقعی صدور ویزا را پیش‌بینی نمی‌کند. خروجی آن یک غربالگری مقدماتی و ابزار بازاریابی است.

# بخش اول: اجرای آزمایشی روی ویندوز

## ۱. ساخت ربات در تلگرام

1. در تلگرام وارد `@BotFather` شوید.
2. دستور `/newbot` را بفرستید.
3. یک نام نمایشی انتخاب کنید؛ مثلاً:
   `Ava Visa Assessment`
4. یک username انتخاب کنید که آخر آن `bot` باشد؛ مثلاً:
   `AvaVisaCheckBot`
5. BotFather یک Token می‌دهد. آن را محرمانه نگه دارید.

## ۲. پیدا کردن Telegram ID مدیر

1. وارد ربات `@userinfobot` شوید.
2. Start را بزنید.
3. عدد نمایش‌داده‌شده مقابل ID را کپی کنید.

## ۳. نصب Python

1. از سایت رسمی Python نسخه 3.12 یا جدیدتر را نصب کنید.
2. در صفحه نصب حتماً گزینه `Add Python to PATH` را تیک بزنید.
3. سپس Command Prompt را باز کنید و بنویسید:

```bash
python --version
```

باید نسخه Python نمایش داده شود.

## ۴. آماده‌کردن فایل تنظیمات

1. فایل `.env.example` را کپی کنید.
2. نام کپی را به `.env` تغییر دهید.
3. فایل `.env` را با Notepad باز کنید.
4. اطلاعات را وارد کنید:

```env
BOT_TOKEN=توکن_دریافتی_از_BotFather
ADMIN_IDS=آیدی_عددی_تلگرام_شما
CONSULTATION_URL=https://t.me/visadesk_consult
BRAND_NAME=آوا
DB_PATH=data/leads.db
```

هیچ فاصله‌ای قبل و بعد علامت `=` نگذارید.

## ۵. نصب کتابخانه‌ها

داخل پوشه پروژه، روی نوار آدرس File Explorer کلیک کنید، `cmd` بنویسید و Enter بزنید. سپس:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## ۶. روشن‌کردن ربات

در همان پنجره بنویسید:

```bash
python bot.py
```

وقتی پیام زیر ظاهر شد، ربات فعال است:

```text
Bot is running...
```

حالا وارد ربات تلگرام شوید و `/start` را بزنید.

برای توقف ربات در پنجره مشکی کلیدهای `Ctrl + C` را بزنید.

# بخش دوم: تنظیم دستورهای ربات

در BotFather:

1. `/mybots`
2. انتخاب ربات
3. `Edit Bot`
4. `Edit Commands`
5. متن زیر را ارسال کنید:

```text
start - شروع ارزیابی رایگان
cancel - لغو ارزیابی
stats - آمار لیدها برای مدیر
export - خروجی اکسل‌خوان لیدها برای مدیر
```

دستورهای `stats` و `export` برای کاربران عادی پاسخی نمی‌دهند.

# بخش سوم: لانچ ۲۴ ساعته روی Railway

## ۱. ساخت مخزن GitHub

1. وارد GitHub شوید و یک Repository خصوصی بسازید.
2. نام پیشنهادی: `ava-visa-bot`
3. تمام فایل‌های این پوشه را آپلود کنید.
4. فایل `.env` را آپلود نکنید.

## ۲. ساخت پروژه Railway

1. وارد Railway شوید.
2. `New Project` را بزنید.
3. گزینه Deploy from GitHub Repo را انتخاب کنید.
4. مخزن `ava-visa-bot` را انتخاب کنید.

## ۳. افزودن متغیرها

در بخش Variables این موارد را جداگانه اضافه کنید:

```text
BOT_TOKEN
ADMIN_IDS
CONSULTATION_URL
BRAND_NAME
DB_PATH
```

مقدار `DB_PATH` را فعلاً این بگذارید:

```text
data/leads.db
```

## ۴. دستور اجرا

Railway معمولاً `Procfile` را تشخیص می‌دهد. اگر اجرا نشد، در Start Command بنویسید:

```bash
python bot.py
```

پس از Deploy شدن، در Logs باید پیام `Bot is running...` دیده شود.

## هشدار مهم درباره دیتابیس Railway

SQLite برای نسخه آزمایشی مناسب است؛ اما فضای فایل سرویس‌های ابری ممکن است دائمی نباشد. برای تبلیغ جدی و لید واقعی، مرحله بعد باید دیتابیس PostgreSQL یا Google Sheets/CRM جایگزین SQLite شود.

# تغییر امتیازها

در فایل `bot.py` بخش `SCORES` را پیدا کنید. برای نمونه:

```python
LANGUAGE: {
    "مدرک معتبر با نمره خوب": 18,
    "مدرک با نمره متوسط": 13,
    "در حال آماده‌سازی": 7,
    "بدون مدرک زبان": 1
}
```

فقط عددها را عوض کنید. مجموع نهایی به‌طور خودکار بین ۰ تا ۱۰۰ محدود می‌شود.

# قبل از تبلیغ گسترده چه چیزهایی باید اصلاح شود؟

1. امتیازدهی باید برای هر کشور توسط تیم پرونده آوا اعتبارسنجی شود.
2. متن رضایت تماس و سیاست حریم خصوصی باید نهایی شود.
3. لیدها باید به CRM منتقل شوند؛ CSV برای مقیاس بالا کافی نیست.
4. باید رویدادهای قیف ثبت شوند: ورود، شروع، رهاکردن، تکمیل و کلیک مشاوره.
5. باید برای معرف موفق پاداش واقعی و قابل‌کنترل تعریف شود.
6. نتیجه‌ها نباید با عباراتی مثل «۹۰٪ شانس قطعی ویزا» تبلیغ شوند.
